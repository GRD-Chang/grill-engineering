派发审查子 Agent 时使用 fork_turns: "none"，提供中立的需求、范围和代码事实，不传递预设结论。审查使用 skill:code-review 的 Standards/Spec 方法，检查当前工作树，包括未提交修改与未跟踪的交付文件，覆盖其默认只比较已提交 HEAD 的做法。探索或并行实现等其他协作按任务需要组织。

完整测试失败时先定向定位和修复，再对收口后的代码复验，不每改一处就跑全量。
